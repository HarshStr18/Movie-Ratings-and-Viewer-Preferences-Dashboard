# 🎬 Movie Ratings & Viewer Preferences Analysis Dashboard

An interactive data analytics dashboard built using Python to analyze movie ratings, viewer preferences, and entertainment trends. This project helps users explore movie popularity, understand audience behavior, and discover patterns in movie ratings through data visualization.

## 📌 Project Overview

**Project Title:** Analysis of Movie Ratings and Viewer Preferences for Understanding Popularity Patterns and Entertainment Trends

The main objective of this project is to analyze movie ratings and viewer preferences using data analytics techniques. The dashboard provides meaningful insights into movie popularity, rating distributions, genre preferences, and audience behavior.

Users can search for movies and explore detailed information through an interactive and user-friendly dashboard.

## ✨ Key Features

- 🔍 **Movie Search:** Search for movies by their titles.
- ⭐ **Movie Ratings:** View average ratings and total number of ratings.
- 📊 **Rating Analysis:** Analyze movie rating distributions and trends.
- 🎭 **Genre Analysis:** Explore different movie genres and audience preferences.
- 📅 **Release Year Analysis:** Analyze movies based on their release years.
- 📈 **Popularity Analysis:** Understand movie popularity using rating-based metrics.
- 📉 **Rating Distribution:** Explore how viewers rate different movies.
- 🎯 **Statistical Insights:** View weighted popularity scores and rating standard deviation.
- 🌙 **Dark Theme UI:** Clean and modern dark-mode dashboard.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Movie-Rating-Analysis.git
```

**2. Navigate to the project folder**

```bash
cd Movie-Rating-Analysis
```

**3. Install the required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```
